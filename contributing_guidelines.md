# Contributing Guidelines 🤝

Thank you for your interest in contributing to this project! We welcome contributions from everyone. 

If you find any **broken links**, **incorrect names**, or want to **add new data**, please follow the guidelines below to submit a Pull Request (PR).

---

## 📌 How You Can Contribute

You can contribute in several ways:
1. **Fixing Issues:** Update broken links, correct misspelled names, or fix errors.
2. **Adding New Data:** Add new relevant resources, links, or entries.
3. **Improving Documentation:** Clarify existing information or formatting.

---

## 🚀 Steps to Submit a Pull Request (PR)

### 1. Fork the Repository
Click the **Fork** button at the top right corner of this repository page to create a copy in your own GitHub account.

### 2. Clone Your Fork
Clone your fork to your local machine:
```bash
git clone https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git
cd REPOSITORY-NAME
```

### 3. Create a New Branch
Create a new branch for your changes:
```bash
git checkout -b update-data
```
*(Use a descriptive name like `fix-broken-links`, `add-new-resource`, or `correct-names`)*

### 4. Make Your Changes
- Edit the files to update links, fix names, or insert new data.
- Ensure the formatting matches the existing file structure.

### 5. Commit and Push
Commit your changes with a clear commit message:
```bash
git add .
git commit -m "Fix broken link for X and update name Y"
git push origin update-data
```

### 6. Create a Pull Request (PR)
1. Go to the original repository on GitHub.
2. You will see a prompt to **Compare & pull request**. Click on it.
3. Provide a clear description of what you changed or added.
4. Click **Create pull request**.

---

## 📋 Rules & Guidelines

- **Accuracy:** Please double-check any links or data before submitting.
- **Formatting:** Keep formatting consistent with the existing markdown files.
- **Clear Commit Messages:** Write short and descriptive commit messages.

Thank you for helping keep this repository updated and accurate! 🎉
